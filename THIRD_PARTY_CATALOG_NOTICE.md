# Public prompt catalog attribution

XAI reads the same public JSON feeds configured by https://canvas-test.pqai.cc/prompts,
from https://github.com/yukkcat/image-prompts/tree/main/dist/sources.
The UI preserves per-record author, original source URL, image URL and prompt.

The registry MIT license covers its synchronization code and documentation only;
it does not relicense upstream prompts, images, names or other creative material.
See https://github.com/yukkcat/image-prompts/blob/main/NOTICE.md and the original
source attached to each card for rights and applicable terms. No third-party
catalog image or complete dataset is redistributed in this application repository
or binaries. Public URL access is not a blanket commercial-use permission.

Configured sources: Banana Prompt Quicker; DavidWu GPT Image 2; Freestylefly GPT
Image 2; Awesome GPT Image; Awesome GPT-4o; YouMind GPT Image 2; YouMind Nano Banana
Pro. The MIT-licensed Banana Prompt Quicker project is by glidea and its community:
https://github.com/glidea/banana-prompt-quicker (Copyright (c) 2025 glidea).

Remote data is treated as untrusted text and URLs, never executable code. A saved
personal card retains attribution and source/image links; its generated outputs
are separate user assets. Test-only CI captures remain temporary artifacts.
