# 工作室视觉与交互整理

本轮在新版工作室及 8 项审计修复的基础上，检查并统一页面、弹窗、字体、边框和点击反馈。改动保留在本地分支，未提交或推送 GitHub。

## 窗口与布局

- 桌面默认窗口从 1440×980 调整为 1280×720，最小从 1100×780 调整为 900×640。
- 首页模式卡片的文字和装饰图使用独立网格区域，避免图片压住标题和按钮。
- 按后续截图要求移除当前模型和新手引导右栏；主区占满导航之外的空间。创作区 1000px 以上为表单与动态两列，较窄窗口改为单列；设置内部帮助区在 1360px 以下堆叠。
- 1000px 以下使用带名称提示的图标导航。
- 表单、画布操作区和工具条允许换行；检查器独立滚动；窗口控制按钮不因窗口变窄而隐藏。
- 760px 以下的浏览器布局继续采用画布与检查器上下排列。

## 文字与控件

| 项目 | 统一规范 |
| --- | --- |
| 字体 | 同一中文优先字体栈：Noto Sans、苹方、微软雅黑及系统后备；输入框、按钮、弹窗一致 |
| 字号 | 辅助文字 12px、说明/标签 13px、正文/输入 14px、分组标题 16px、标题 22px、主标题 32px |
| 字重 | 常用 400 / 500 / 600，避免大量不一致的中间字重 |
| 示例 | 示例型占位文本统一为“例如：…”，输入说明与真实默认值区分 |
| 圆角 | 控件 12px、卡片 16px、面板/弹窗 20px |
| 边框 | 统一浅蓝灰边框，配合较深正文和说明文字，提高浅色背景上的辨识度 |
| 控件 | 常用按钮约 40–42px 高，输入约 42–44px 高；图标操作保留至少 32px 点击区 |

真实界面文字不再使用原先的 7–11px 微小字号。品牌标识和首页装饰插画内部文字保留其图形尺寸。

## 弹窗与动画

- 普通、宽版、媒体弹窗最大宽度分别为 620 / 860 / 1120px，并受可用窗口宽高约束。
- 配置、提示词编辑/详情、优化确认、导入和媒体预览统一标题、关闭按钮、内容及操作区。
- 长内容独立滚动，主要操作固定；点击弹窗内部空白不再误关闭。
- 添加标题关联和窄导航的可访问名称，保留原生对话框的焦点约束及 Escape 关闭。
- 悬停轻微抬升，按下为 0.98 倍缩放和 1px 下移，使用约 180ms 缓动；弹窗约 220ms 淡入。
- 动画不改变画布节点的世界坐标；系统减少动态效果时关闭过渡、入场和交互位移。

## 验证

- 使用本地 Chromium 实际渲染 1440×900、1280×720、900×640 三种尺寸。
- 检查首页、创作、作品、资源、工作流、历史、设置、上游配置弹窗、画布及资源抽屉：正文容器无横向溢出，可见操作未超出窗口左右边界；真实内容文字不小于 12px。
- Windows 样式模式下检查悬停/按压差异、输入焦点、弹窗 Tab 焦点约束、内边距点击、遮罩点击、Escape、固定操作区及减少动态效果；提示词表单填写和本地保存成功。
- 前端 338 项测试通过；TypeScript 与 Linux 目标生产构建通过；`git diff --check` 通过。

本轮没有调用真实生图接口。浏览器渲染与样式模式检查不等同于 Windows WebView2 或 macOS WKWebView 的原生运行验收；系统原生下拉菜单和字体光栅化仍可能随平台不同。

主要样式入口为 `studio.css`（布局）、`polish.css`（文字与视觉变量）、`dialogs.css`（弹窗结构）和 `motion.css`（动效），由 `StudioRoot.tsx` 统一加载。

## 截图反馈调整

- 快捷操作仅保留“图片、视频、最近、新建工作流”四项；删除副文案及第五个导入入口，创作表单中的参考图导入仍可使用。
- 四个按钮的标题放大至 22–24px，保留原字体、字重、配色与动效；图标和标题水平居中，卡片高 104px。桌面四等分，561–1000px 为两行两列，560px 以下单列。
- 删除右栏的渲染、专用统计逻辑和失效样式，不留下空列。
- 新增 `JobResultThumbnails.tsx`：创作动态及历史任务显示本地成品缩略图，支持旧单结果字段与多结果字段，点击进入已有作品预览。无成品任务不伪造图片；缺失或已删除素材不显示，文件加载失败有明确提示。
- 使用独立浏览器测试数据验证了 1440×900、1280×720、900×640 的快捷操作、图片/视频切换、旧记录缩略图、多图去重和点击预览，页面无横向溢出；结果辅助函数的 3 项测试及生产构建通过。测试数据未写入源码或用户的真实项目。
