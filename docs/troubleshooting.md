# 数据位置与故障排除

## 先确认配置

1. 阅读设置中接口协议的 TIPS，核对 xAI 原生 / OpenAI 兼容、Images / Responses 和实际 API 根路径。
2. 测试连接仅读取 `/models`；模型列表可见不能证明图片、文本工具、编辑或参数权限。
3. 核对精确模型 ID、Key 分组、额度、模型映射，以及该接口是否由上游实现。
4. 记录任务状态和上游错误；同样配置在上游调试页失败时，也需检查部署和账号。

sub2api 的桥接策略、请求示例和验收清单见 [sub2api 接入](./sub2api.md)。

## 数据保存在哪里

| 数据 | 当前工作室位置 |
|---|---|
| API Key | 系统凭据库：Keychain / Credential Manager / Secret Service |
| 上游、项目、任务、历史元数据 | `os.UserConfigDir()/ImageStudio/studio-v2/studio.json` |
| 图片与视频 | 同一目录下的 `media/` |
| 浏览器预览 | IndexedDB；不保存 API Key、不提供收费生成 |
| 旧历史来源 | 原本的输出目录、浏览器本地历史；迁移不会删除源文件 |

系统配置根目录因平台而异；它不是旧版的 `~/Pictures/Image Studio/` 输出目录。经典编辑入口已经移除。旧版本 `images/`、`log/` 和 IndexedDB 记录仍可能存在，不能把它们当成当前全部数据的位置。

旧历史未显示时检查源文件是否仍可读。迁移失败会保留记录，可以修复路径或存储问题后重新打开工作室。不要以删除旧数据库作为升级排错的第一步。

## 524 / 504 / 5xx / 断流

这类错误可能发生在上游已接受、正在生成或已经计费之后。工作室不会自动重新提交图片任务；结果未知时先查询上游，不要连续点击生成。

- Images 和 Responses 都可能支持 SSE。先确认当前上游真正返回事件、反向代理没有缓冲流式数据。
- SSE 可以减少空闲超时，但不能保证消除所有网关超时。
- 只有预览帧不代表成功。没有最终图或明确终态时应保留不完整或不确定状态。
- 切换到另一协议、传输或账号会形成新请求；需要明确重新提交，不能视作免费恢复。
- 已保存结果链接的下载失败可恢复下载，不必重新生图。

## WebSocket 握手失败

`WebSocket upgrade required`、HTTP 400 等提示可能表示代理没有转发 Upgrade，或上游只实现 HTTP Responses。核对设置中的完整 API 根路径和代理支持，先在 HTTP SSE 下单独验证。

不要根据握手成功认定完整生图和编辑已经可用。连接中断后的任务可能仍在运行；只有能确认请求未被接受时，重试或传输降级才是安全的。

## 401 / 403 / model not found

Responses 要求文本模型可用且能调用 `image_generation`；图像模型放在工具配置，不能拿文本模型替代。Images-only 分组不一定允许 Responses。Images 要求相应生成或编辑端点及图像模型权限。模型映射、额度、IP 白名单也可能导致拒绝。

修改 Key、地址、模型、协议或预设后，旧能力记录失效，需要重新确认。连接测试不会自动生成收费图片验证权限。

## 多参考图、蒙版或扩展参数不生效

- 数量上限与格式取决于精确模型和路径。不能断言所有标准 Images 编辑只接受单图，也不能假设所有 relay 接受相同 multipart 字段。
- 蒙版使用原图坐标，尺寸必须匹配；先用已知样例确认透明区域的编辑含义。
- `seed`、`negative_prompt`、input fidelity 等仅在对应能力确认时使用；中转接受字段不等于实际转发并执行。
- `gpt-image-2*` 的 input fidelity 不能统一强制。原生 Images、网关内部 Responses 与直接 Responses 的字段行为可能不同。
- PNG 避免额外有损压缩，不保证更佳构图。插值后的像素数不代表更高模型原生分辨率。

## 提交问题时需要的信息

提供平台（Windows/macOS/Linux）、XAI 提交或版本、协议、脱敏 Base URL 类型、精确模型 ID、最短复现步骤、任务状态、错误 message 和可用 request ID。不要附完整 API Key、Cookie 或 OAuth 凭据。

区分自动化 mock、真实上游测试和系统宿主测试。UI、持久化、解析或参数构造的可复现错误适合提交本仓库；网关权限和额度也应同步联系上游。浏览器预览不能用于证明系统凭据库和桌面文件操作可用。
