# PR #9 架构合并与迁移说明

本轮基于 `9267205c2159c34bb6ec668c8523ce0346f9a5f0`，落实经典编辑与 Studio 的执行、凭据、历史和媒体合并。经典界面保留，作为共享引擎的另一套操作界面。

## 已接通的架构

| 附件事项 | 本轮结果 |
| --- | --- |
| 2.1 任务执行 | 经典图像、编辑、视频提交到 Studio 持久队列，使用 `classic` 项目；进度与结果事件由同一任务产生。保留多参考图、蒙版、生成参数及预览。 |
| 2.1 保守重试 | 仅确认未取得连接的生成可自动重试或切换备用上游。524、断流、WebSocket 已发送后的断线不重放。429 也不自动重发生成。备用配置和凭据槽在提交时冻结。 |
| 2.2 视频 | go-cli `VideoRunner` 统一创建、查询、下载；Studio 先保存远端 ID/结果链接，再轮询或下载。支持创建时直接返回成品，拒绝未通过上游审核的结果。经典视频返回共享素材 URL；停止轮询会取消共享后端任务，也覆盖创建响应尚未返回的情况。 |
| 2.2 历史与媒体 | 新素材按 SHA-256 去重；经典旧文件复制到共享库，原文件保留；导入时保留编辑模式与改写提示词。稳定任务 ID 保证重复导入幂等。经典删除/清理记录同步到共享任务历史。 |
| 2.3 端点 | HTTP Responses、WebSocket、提示词优化与浏览器远程内核统一使用原样 API 根路径规则；上游编辑显示最终地址。 |
| 2.4 凭据 | 桌面请求走 Go，前端日常状态只使用 `hasKey`。设置里点显示才读取保存的密钥；隐藏时清空后端读取的值，保留用户尚未保存的新输入；切换、关闭时清空。留空保存保留旧密钥；连接测试与提示词优化禁止携带凭据跟随重定向。 |
| 2.5 降级 | 共享注册表打不开时，上游配置只读并显示原因；拒绝修改、删除、复制和清除密钥。 |
| 2.6 版本 | schema 升级到 v2，升级前原样备份 v1；损坏文件、未来版本、备份失败均拒绝覆盖。 |
| 3 下载代理 | 结果链接及每次重定向先通过校验后的直连；仅配置上游的同源地址在直连连接失败后允许代理回退。结果 URL 不携带 API Key。 |
| 3 SSE | 识别 `event: error`、无空格的 `data:` 与多行数据；保留旧中转站逐行 JSON 的兼容性。 |
| 4.1 生命周期 | 终态任务可删除或按天数归档。画布和素材软删除，保留 30 天，可恢复。启动时及每天清理过期回收站与超过 30 天的无索引媒体文件。 |

共享引擎限制每个上游的并发提交。已有远端 ID 或结果链接的查询/下载不占提交名额。仍被 Studio 画布（含回收站）、经典画布和打开的查看器、历史任务、提示词卡片引用的素材不会被回收；先移除引用才能将素材移入回收站。归档文件保存任务元数据，不嵌入媒体。经典画布的素材引用会持久化；移除画布节点并关闭相应查看器后，才可回收不再被其他对象引用的素材。

经典错误详情仍提供诊断日志：共享请求保存已脱敏的最后 256 KiB 响应片段，避免把大量预览帧写进数据库。日志不是完整响应归档，沿用原日志保留设置。

## 升级与历史导入

1. 正常退出旧应用，备份应用配置目录、旧输出目录以及 WebView 数据。不要在迁移期间同时运行两个版本。
2. 新版读取有效 v1 时，创建 `studio.v1.json.bak`，已有备份不覆盖；随后持久化操作写 v2。
3. 打开经典编辑后，旧历史按每批 100 条导入。源文件不可读或库已满的条目会保留本地并提示，可修复路径/归档后重启再试。
4. 新生成结果统一存放在 `studio-v2/media`。旧输出文件不会被自动删除；旧 Studio 素材索引继续可读，不在启动时批量改写存量文件。新导入/生成的内容使用 SHA-256 地址。
5. “设置 → 历史归档与回收站”提供归档及恢复操作。归档后的任务从两套界面的共享历史移除，素材仍在库中，可单独保存。

Studio 数据目录由系统配置目录决定：Windows `%APPDATA%/ImageStudio/studio-v2`；macOS `~/Library/Application Support/ImageStudio/studio-v2`；Linux `$XDG_CONFIG_HOME/ImageStudio/studio-v2`（未设置时为 `~/.config/ImageStudio/studio-v2`）。

## 降级

1. 退出新版，并另外复制保存当前 `studio.json`、媒体目录与 WebView 数据。
2. 用 `studio.v1.json.bak` 的副本替换 `studio.json`，再启动旧版。旧版不能直接读写 v2。
3. 备份之后新增的任务、上游设置、回收站状态不会出现在旧版中；不要删除新版备份或共享媒体。恢复新版时可换回其数据库。
4. 数据库备份不包含系统凭据库。升级后若轮换/清除了旧凭据，降级后可能需要重新填写密钥；不要把密钥写入数据库文件。

## 本轮边界与待办

仍使用单文件 JSON；SQLite、按需加载画布/历史分页接口、大画布虚拟化、全面拆分 store/绑定类型属于后续独立变更。Android 删除、视频画质增强、远端取消不在本轮。取消只停止本地操作，上游仍可能执行或计费。

已有素材不进行破坏性搬移，旧输出目录需在确认迁移及备份后人工清理。归档 JSON 没有恢复导入界面。被冻结的凭据槽被外部删除时，本轮不提供“使用当前密钥恢复”操作。

自动验证使用临时目录、浏览器隔离上下文与本地模拟上游，不发出收费请求。真实上游、三大系统凭据库、Clash Fake-IP 和原生 WebView 的真实环境验收仍需在对应环境进行。
